Plugins / ClaimsForge

PlaceholderAPI

ClaimsForge provides 3 placeholders via PlaceholderAPI for use in scoreboards, tab lists, chat formatting, and holograms.

Available placeholders

Placeholder Returns Example
%claimsforge_count% Number of chunks the player has claimed 3
%claimsforge_limit% Max chunks the player is allowed to claim 15
%claimsforge_in_claim_of% Owner name of the current chunk, or Wilderness Steve

Setup

  1. Install PlaceholderAPI on your server
  2. ClaimsForge registers its expansion automatically on startup — no /papi ecloud download needed
  3. Use the placeholders in any PAPI-compatible plugin

Usage examples

CMI Scoreboard

Scoreboard:
  - "&7Claims: &b%claimsforge_count%&7/&b%claimsforge_limit%"
  - "&7Location: &e%claimsforge_in_claim_of%"

TAB Plugin (TAB by NEZNAMY)

header: "&bYou have &e%claimsforge_count%&b claims"

EssentialsX Join Message

join-message: "&a%player% &7entered &e%claimsforge_in_claim_of%"

Hologram (DecentHolograms)

lines:
  - "&b🏠 Claims: &e{papi: claimsforge_count}&b/&e{papi: claimsforge_limit}"

Note: The %claimsforge_in_claim_of% placeholder updates in real-time as the player moves between chunks.
