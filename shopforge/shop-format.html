Plugins / ShopForge

Shop format

Each shop is a YAML file in plugins/ShopForge/shops/. Here is the full format reference.

Complete shop file

# shops/blacksmith.yml

id: blacksmith                 # used in /shop <id> and shopforge.use.<id>
display-name: "<gray>⚒ Blacksmith"

categories:
  swords:
    icon: DIAMOND_SWORD        # the category tab
    display-name: "<aqua>⚔ Swords"
    items:
      - id: diamond_sword
        material: DIAMOND_SWORD
        display-name: "<aqua>Diamond Sword"
        lore:
          - "<gray>Forged at the anvil."
        buy-price: 500.0         # 0 or less = can't be bought
        sell-price: 200.0        # 0 or less = can't be sold
        enchants:
          sharpness: 3
          unbreaking: 2

      - id: iron_sword
        material: IRON_SWORD
        buy-price: 100.0
        sell-price: 40.0

  armor:
    icon: DIAMOND_CHESTPLATE
    display-name: "<yellow>🛡 Armor"
    items:
      - id: diamond_chestplate
        material: DIAMOND_CHESTPLATE
        buy-price: 800.0
        sell-price: 350.0
        stock: 10                # only 10 for the whole server
        stock-per-player: 1      # each player can buy 1

  special:
    icon: NETHERITE_SWORD
    display-name: "<gold>⭐ Special"
    items:
      - id: godly_sword
        material: NETHERITE_SWORD
        display-name: "<gradient:gold:red><bold>Godly Blade</bold></gradient>"
        buy-price: 5000.0
        stock: 1
        stock-per-player: 1
        permission: shop.vip     # only players with this permission can buy it
        enchants:
          sharpness: 5
          fire_aspect: 2
          mending: 1

Items can also be written as a map keyed by id (diamond_sword: instead of - id: diamond_sword); both load the same.

Item field reference

Field Type Default Description
id String — Unique id inside the shop (used in logs and /shop give)
material String PAPER Bukkit Material name
display-name String material name MiniMessage name shown in the menu
lore List [] MiniMessage lines shown in the menu
buy-price Double 0 Cost to buy; 0 or less = can't be bought
sell-price Double 0 Sell value; 0 or less = can't be sold
permission String — Permission needed to buy the item
stock Integer -1 Stock shared by the whole server; -1 = unlimited
stock-per-player Integer 0 How many each player can buy; 0 = no limit
stock-refill-hours Integer 24 Hours until a player's own limit resets
enchants Map {} enchantment: level pairs (Minecraft names)
skull-texture String — Texture id for PLAYER_HEAD items (the hash at the end of a textures.minecraft.net/texture/... link)

per-player-limit and enchantments are also accepted. Any other key is ignored and reported in the console when the shop loads.

What the buyer receives. If display-name is just the item's own name in colour (<white>Iron Sword on an IRON_SWORD), the player gets the plain item, without name or lore, so it stacks with the ones they already have. A name of its own (<gold>Legendary Key) is kept on the delivered item together with its lore. Enchantments and skull textures are always kept.

Server stock vs per-player limit

  • stock: one pool for everyone. When it reaches 0, nobody can buy.
  • stock-per-player: each player can buy up to this many, counted per player, and their count resets every stock-refill-hours.

The menu shows what's left: Stock: 7 for server stock, Stock: 1 (per player) for a player's own limit.

Example — limited edition item:

      - id: legendary_key
        material: TRIPWIRE_HOOK
        display-name: "<gold>Legendary Key"
        buy-price: 10000.0
        stock: 50              # only 50 for the whole server
        stock-per-player: 1    # each player can get 1
