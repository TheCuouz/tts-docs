Plugins / ShopForge

Shop editor

/shop editor makes and changes shops from inside the game. Everything it does lands in the same YAML files described in Shop Format, so you can switch between the editor and a text editor whenever you like.

Permission: shopforge.editor (op by default, and part of shopforge.admin).

The list of shops

Button What it does
A shop Opens it in the editor
+ New shop Asks for the name in chat (colours allowed: <gold>Mine Shop) and creates shops/<id>.yml
How it works A reminder of the steps below

/shop editor <shop> jumps straight into one shop.

A new shop stays hidden from players' /shop list until it sells at least one item.

A category

Click any item in your own inventory (the bottom half of the window) to put it on sale here. Its name, description, enchantments — or its ItemsAdder / Nexo / Oraxen / MMOItems id — come with it, and when the same item is already sold in one of your shops its prices are copied over. + Add item does the same with the item in your hand.

Along the top: back, rename, icon (click holding the new one), move the tab earlier or later, and delete the category with its items.

Saving and backups

  • Every click is saved to the file and the shops reload at once — there is no Save button to forget, and nothing is lost if the server stops.

  • Each click reads the file first, so two admins editing at once, or a change you make by hand between two clicks, are never overwritten.

  • Only the keys you change are rewritten. Lore, skull textures, the comments at the top of the file (on 1.18+) and items written as a map keyed by id stay as they were.

  • The first change to a shop after each start copies its file to plugins/ShopForge/backups/editor/<id>-<date>.yml; the last five per shop are kept.

  • In chat, type cancel to leave a question without changing anything. A question nobody answers lets chat through again after two minutes.

Bedrock players

Through Geyser the editor arrives as Bedrock forms, one button per option. Typing in chat works the same; adding an item uses + Add item with the item in hand.

What it does not copy

ShopForge sells an item by its material, name, description and enchantments. Anything else on the item you click — potion effects, banner patterns, book contents, custom model data — is not kept (custom items from ItemsAdder, Nexo, Oraxen and MMOItems are kept whole, by their id).
