TTS-Studio plugin documentation

Sixteen Paper plugins, each documented from its own source: the commands and permissions you read here are the ones the plugin registers, and the configuration reference is the file it writes on first start. When a plugin changes, this site is rebuilt from it.

Before you install anything

  • Paper 1.21.x on Java 21. Purpur works. Spigot and Bukkit are not supported, and the plugins say so on startup instead of failing halfway through.
  • Drop the jar in plugins/ and start the server. Every plugin writes its own configuration on first run; none of them need a database you have to set up first.
  • Optional integrations stay optional. Vault, PlaceholderAPI, Citizens and the rest are detected at runtime: if one is missing, that feature switches itself off and says so in the console. No plugin here refuses to start because another one is absent.
