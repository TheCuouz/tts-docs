Plugins / EnchantsForge

Configuration reference

This is the config.yml EnchantsForge writes on first start, comments included. Every key you see here is the key the plugin reads; there are no hidden ones. Change a value, reload, and it applies.

Top-level sections: language, license-key, altar, anvil, enchants.

# =============================================================================
#  EnchantsForge — main config
# =============================================================================
#  Custom enchantments suite by TTS-Studio.
#  All player-facing strings live in lang/{es,en}.yml (MiniMessage tags).
#  This file controls language, licensing, XP economy, and per-enchant tuning.
# =============================================================================

# -----------------------------------------------------------------------------
# Language
# -----------------------------------------------------------------------------
# Active language. ISO-639-1 two-letter code (lowercase).
# Bundled out of the box: es (Spanish), en (English).
# Missing keys fall back to en automatically. Operators can drop extra
# lang/<code>.yml files in plugins/EnchantsForge/lang/.
language: en

# -----------------------------------------------------------------------------
# Licensing
# -----------------------------------------------------------------------------
# Your BuiltByBit license key. Leave empty in dev / SpigotMC freebie builds.
license-key: ""

# -----------------------------------------------------------------------------
# Altar
# -----------------------------------------------------------------------------
# The Enchanting Altar lets players open a 6-row GUI by right-clicking a
# valid Beacon structure (Beacon + 4 Obsidian at ±2 + an Enchanting Table
# within 3 blocks).
altar:
  # Multiplier on every enchant's XP cost when applied via the altar GUI.
  # 1.0 = exactly as defined by each enchant. 0.5 = half price, 2.0 = double.
  xp-cost-multiplier: 1.0

# -----------------------------------------------------------------------------
# Anvil
# -----------------------------------------------------------------------------
# Cost adjustments when combining an enchant book with an item in an anvil.
anvil:
  # Multiplier on the XP cost of every anvil combine. 1.0 = vanilla cost.
  xp-cost-multiplier: 1.0

# -----------------------------------------------------------------------------
# Per-enchant tuning
# -----------------------------------------------------------------------------
# Knobs exposed by individual enchant implementations. Adding a new enchant
# in your own code typically means adding a section here too.
enchants:
  wings:
    # Maximum number of mid-air jumps before the player must touch the ground
    # again. 1 = classic double-jump.
    max-jumps: 1

  magnetic:
    # Pulling strength applied to nearby items each tick. Higher = items snap
    # to the player faster, but also feels more "magical."
    pull-speed: 0.15

  frost-walker-plus:
    # How long (in ticks) frosted ice survives before melting. Vanilla
    # FrostWalker uses roughly 80 ticks (~4 seconds).
    ice-duration: 80
