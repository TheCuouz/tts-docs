Plugins / EnchantsForge

EnchantsForge

Build the Altar, then earn the enchantment

EnchantsForge adds 17 custom enchantments to Paper 1.21, from Telekinesis and Auto Smelt to Soulbound and Wings. Players apply them at an Altar they build in the world, and the enchantments stay on the item through anvil renames, stack splits and trades.

How it works in play

  • Build the Altar: a beacon, four obsidian two blocks out on each side and an enchanting table within three blocks. Right-click the beacon to open it.
  • Pick an enchantment: place a sword and you see sword enchantments, each with its rarity, max level and XP cost. Click one, the XP comes off, and it's on the item.
  • Read what each one does: /enchant browse lists every enchantment with what it does and what it applies to; /enchant info <id> shows one.
  • Books: staff hand out enchantment books at any level (/enchantbook), so they work as crate prizes, shop items or event rewards. Players apply them at an anvil.

The seventeen

  • Legendary: Soulbound (kept on death), Wings (double and triple jump).
  • Epic: Explosive (block-safe blast on hit), Thunderstrike (lightning on a critical hit), Vampiric (hearts back on a kill).
  • Rare: Lifesteal, Beheading, Wither, Telekinesis, Auto Smelt, Nether Step, Frost Walker+.
  • Uncommon: Excavator (3×3, never inside protected land), Magnetic, Replenish, Spring Boots, Iridescent (cosmetic, drawn with ParticleForge if it's installed).

How to use it

  1. Install: drop the jar into /plugins and restart once. English is the default; set language: es for Spanish.
  2. Build an Altar anywhere: beacon in the middle, obsidian two blocks out on each side, an enchanting table close by.
  3. Enchant: right-click the beacon, place the item, click an enchantment.
  4. Tune the economy: altar.xp-cost-multiplier and anvil.xp-cost-multiplier in config.yml (0.5 is half price, 2.0 double). Wings jumps, Magnetic pull speed and Frost Walker+ ice duration are there too.

Commands and permissions

  • Everyone (enchantsforge.use): /enchant browse, /enchant list, /enchant info <id>.
  • Operators (enchantsforge.admin): /enchant give, /enchantbook <id> <level> [player], /ef reload.

Requirements

  • Paper 1.21 on Java 21.
  • Optional: PlaceholderAPI (%customenchants_count_in_hand%, %customenchants_total_levels_in_hand%) and ParticleForge (for Iridescent's burst).

Neither is required. Without them the placeholders aren't registered and Iridescent is simply quieter. The plugin never refuses to start because an optional plugin is missing.

FAQ

Do enchantments disappear if someone renames the item?
No. They're stored in the item's own data, not read back from its description, so anvil renames, stack splits and trades keep them.

Does Minecraft's /enchant still work?
Yes. Vanilla enchanting and the vanilla command work next to the custom ones.

Can Excavator grief protected areas?
No. It skips any block the player isn't allowed to break, so claims and protected regions stay intact.

Can I add my own enchantments?
Yes. Extend CustomEnchant, register it through getRegistry(), and hook hits, kills, damage taken, block breaks, shots, arrow hits or a per-tick effect.

Can I translate the messages?
Yes. English and Spanish are included in lang/, in MiniMessage, and missing keys fall back to English.

Do I need a license key?
No. The plugin has no license check.
