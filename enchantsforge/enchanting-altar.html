Plugins / EnchantsForge

Enchanting altar

The Enchanting Altar is a multi-block structure that lets players apply custom enchantments through an interactive GUI. It is the primary way to enchant items with EnchantsForge.

Renamed: EnchantsForge was previously released as "CustomEnchants". The Altar mechanic is unchanged.

Build structure

The Enchanting Altar requires exactly 6 specific blocks arranged in the correct pattern:

         [EnchantingTable]
                 |
    [Obsidian][Beacon][Obsidian]
                 |
    [Obsidian]       [Obsidian]

Top-down layout (same Y level for base blocks):

  [ ]  [OBS] [ ]
 [OBS][BEAC][OBS]
  [ ]  [OBS] [ ]

Then place the Enchanting Table on top of the Beacon:

  Vertical view:
    [EnchantingTable]  ← Y+1 above Beacon
    [    Beacon     ]  ← Center block
    [   Obsidian   ]   ← 4 surrounding blocks at same Y as Beacon

Exact Block Placement

Block Position Notes
Beacon Center (0, 0, 0) The "core" of the altar
Enchanting Table Directly above Beacon (0, +1, 0) Must be 1 block above
Obsidian (×4) N/S/E/W of Beacon, same Y level Cardinal directions, 1 block away

Required Blocks Checklist

  • [ ] 1× Beacon
  • [ ] 1× Enchanting Table
  • [ ] 4× Obsidian

Warning: Regular obsidian must be used — Crying Obsidian will NOT work for this structure (Crying Obsidian is used in the V2 Fusion Altar instead).

Note: The Beacon does not need a pyramid base — just the bare Beacon block is sufficient.

How to use the altar

Step 1 — Locate your Altar

Ensure all 6 blocks are placed correctly. The altar is detected automatically when you interact with the Enchanting Table.

Step 2 — Right-Click the Enchanting Table

Right-click the Enchanting Table (the top block) to open the Enchanting Altar GUI.

Note: Right-clicking the Beacon or the Obsidian blocks will not open the GUI.

Step 3 — Place Your Item

The GUI will open with slot for your item. Place the item you wish to enchant in the designated item slot.

Step 4 — Browse Available Enchantments

The GUI shows all enchantments compatible with your item. Each enchant displays:

  • Enchant name and level
  • Description of the effect
  • XP cost to apply
  • / Compatibility status

Step 5 — Select an Enchantment

Click an enchantment to apply it. You will be charged the XP cost displayed. If you don't have enough XP, the enchantment cannot be applied.

Step 6 — Retrieve Your Item

Take your enchanted item from the GUI. The enchantment data is stored in the item's PersistentDataContainer.

XP costs

Enchantment costs scale with level and can be adjusted in config.yml:

altar:
  cost-multiplier: 1.0  # 1.0 = default costs; 0.5 = half price; 2.0 = double price

Tip: Lower the cost-multiplier on servers where XP is hard to obtain, or raise it to make enchanting more prestigious.

Conflict enforcement

The altar enforces the conflict system. If an item already has an enchantment that conflicts with another, the conflicting enchantment will be greyed out and unclickable in the GUI.
