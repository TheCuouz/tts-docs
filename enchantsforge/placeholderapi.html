Plugins / EnchantsForge

PlaceholderAPI

EnchantsForge integrates with PlaceholderAPI to provide placeholders for scoreboards, chat, GUIs, and other plugins.

Renamed: EnchantsForge was previously released as "CustomEnchants". The PAPI placeholder identifier is still customenchants (kept stable so existing scoreboards keep working).

Requirements

Dependency Version
PlaceholderAPI 2.11+

Note: PlaceholderAPI is optional. If PAPI is not installed, the plugin will still function normally — placeholders just won't be available.

Available placeholders

Placeholder Returns Example Value
%customenchants_count_in_hand% Number of EnchantsForge enchants on the item in the player's main hand 3
%customenchants_total_levels_in_hand% Sum of all EnchantsForge enchantment levels on the held item 7

Note: The customenchants_ prefix on the placeholders is a stable identifier — it does not change with the plugin's display name. EnchantsForge's PAPI startup log line will still report 8 enchants · PAPI.

Placeholder descriptions

%customenchants_count_in_hand%

Returns the count of distinct EnchantsForge enchantments on the item currently held in the player's main hand.

Example use cases:

  • Show how many custom enchants are on a weapon in a scoreboard
  • Conditional displays in GUIs (show upgrade button only if < 3 enchants)
# Example scoreboard line
Enchants: %customenchants_count_in_hand%

Returns:

  • 0 — No EnchantsForge enchantments on held item, or no item held
  • 3 — Item has 3 EnchantsForge enchantments (e.g., Lifesteal, Vampiric, Beheading)

%customenchants_total_levels_in_hand%

Returns the sum of all level values of EnchantsForge enchantments on the held item.

Example use cases:

  • Display total "enchant power" of a weapon
  • Leaderboard of strongest enchanted items
# Example scoreboard line
Enchant Power: %customenchants_total_levels_in_hand%

Returns:

  • 0 — No EnchantsForge enchantments
  • 7 — Item has Lifesteal III + Vampiric II + Beheading II (3+2+2 = 7)

Setup

  1. Install PlaceholderAPI on your server
  2. Restart the server (or run /papi reload)
  3. Use the placeholders in any PAPI-compatible plugin
# Test a placeholder in-game
/papi parse me %customenchants_count_in_hand%

Usage examples

Scoreboard (CMI / FeatherBoard / AnimatedScoreboard)

lines:
  - "&6Custom Enchants: &e%customenchants_count_in_hand%"
  - "&6Total Power: &e%customenchants_total_levels_in_hand%"

Chat Format (EssentialsX / LuckPerms Chat)

{player} [CE:%customenchants_total_levels_in_hand%]: {message}

HolographicDisplays / DecentHolograms

{papi: %customenchants_count_in_hand%} enchants active
