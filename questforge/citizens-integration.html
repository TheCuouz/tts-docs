Citizens Integration

Citizens Integration

With Citizens 2.0.35+ installed, NPCs can hand out quests and take part in them. Without Citizens everything else keeps working; only the NPC parts are skipped.

Quest givers

A quest giver is an NPC that opens a quest log with only its own quests when right-clicked. Completed quests are hidden from it.

  1. Create the NPC, or pick an existing one: /npc create Guard
  2. Select it (look at it): /npc select
  3. Tell QuestForge which quests it gives: /quest admin npc welcome bounty_hunter

Other forms:

Command Effect
/quest admin npc Shows the quests of the selected NPC
/quest admin npc <id> [id...] Replaces its list with these quests (spaces or commas)
/quest admin npc clear It stops being a quest giver

Needs questforge.admin. The list is stored by Citizens with the NPC, so it survives restarts.

NPCs inside a quest

Two objective types point at an NPC by its Citizens id (/npc list shows it):

  • TALK — right-click the NPC.
  • DELIVER — hand the NPC a number of items.

The NPC in an objective does not need to be a quest giver. See Objective Types for the keys.
