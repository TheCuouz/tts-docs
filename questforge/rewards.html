Rewards

Rewards

Rewards are given as soon as the last objective is done. The four types can be combined.

rewards:
  money: 500.0
  xp: 200
  items:
    - material: DIAMOND
      amount: 3
    - material: IRON_SWORD
      amount: 1
  commands:
    - "lp user %player% parent add hunter"
    - "broadcast %player% is now a bounty hunter!"
Key Description
money Paid through Vault. Needs Vault and an economy plugin; without them it is skipped
xp Experience points (not levels)
items List of material + amount. If the inventory is full, the rest drops at the player's feet
commands Run by the console. %player% is replaced with the player's name

Money and XP are confirmed in chat.
