Plugins / QuestForge

PlaceholderAPI

PlaceholderAPI

QuestForge registers 3 placeholders via PlaceholderAPI for use in scoreboards, holograms, tab lists, and chat formatting.

PlaceholderAPI is a soft dependency. If it isn't installed, the expansion is simply not registered — see Compatibility.

Available Placeholders

Placeholder Returns Example
%questforge_active% Number of quests the player has active 2
%questforge_completed% Total quests completed by this player 14
%questforge_progress_<id>% Progress string for a specific quest 7/10

Setup

QuestForge registers its expansion automatically on enable when PlaceholderAPI is detected. No /papi ecloud download needed. You'll see the registration confirmed by the TTS-Studio console banner's PAPI hook indicator at startup.

Usage Examples

Scoreboard (CMI)

lines:
  - "&eActive Quests: &b%questforge_active%"
  - "&eCompleted: &a%questforge_completed%"
  - "&7Bounty Hunter: &f%questforge_progress_bounty_hunter%"

Hologram (DecentHolograms)

lines:
  - "&6Quest Progress"
  - "&7Bounty Hunter: &e{papi: questforge_progress_bounty_hunter}"

Tab Plugin

footer: "&7Quests done: &a%questforge_completed%"

Note: %questforge_progress_<id>% returns 0/N if the quest hasn't been accepted, and Done if it has been completed (for non-repeatable quests).
