Plugins / CrateForge

PlaceholderAPI

PlaceholderAPI

CrateForge integrates with PlaceholderAPI to expose player data for use in scoreboards, chat, GUIs, and other plugins.

Requirements

Dependency Version
PlaceholderAPI 2.11+

Note: PAPI is optional. CrateForge works without it — placeholders are simply unavailable.

Available Placeholders

Placeholder Returns Example Value
%crateforge_opens% Total number of crates opened by this player (all crates combined) 142
%crateforge_tokens_<type>% Token balance of the specified type for this player 500

Placeholder Descriptions

%crateforge_opens%

Returns the total count of all crate opens this player has ever performed across all crate types.

# Example scoreboard line
Total Opens: %crateforge_opens%

Example values: - 0 — Player has never opened a crate - 50 — Player has opened 50 crates total - 142 — Player has opened 142 crates total

%crateforge_tokens_<type>%

Returns the player's balance for the specified token type. Replace <type> with your token type ID.

# Check premium tokens
%crateforge_tokens_premium%

# Check vote tokens
%crateforge_tokens_vote%

# Check event tokens
%crateforge_tokens_event%

Example values: - 0 — No tokens of this type - 500 — Player has 500 premium tokens

Setup

  1. Install PlaceholderAPI on your server
  2. Restart the server (or /papi reload)
  3. Use placeholders in any PAPI-compatible plugin
# Test placeholders in-game
/papi parse me %crateforge_opens%
/papi parse me %crateforge_tokens_premium%

Usage Examples

Scoreboard (FeatherBoard / FastBoard / CMI)

lines:
  - "&6Crate Opens: &e%crateforge_opens%"
  - "&bTokens: &f%crateforge_tokens_premium%"

Chat Format (EssentialsX / LuckPerms)

[Opens: %crateforge_opens%] {player}: {message}

HolographicDisplays / DecentHolograms

{papi: %crateforge_opens%} total opens

Conditional Display (CMI / DeluxeMenus)

# Show a "VIP" tag if player has 100+ opens
condition: "%crateforge_opens% >= 100"

Leaderboard (SuperVanish / LeaderHeads)

# Configure a leaderboard for %crateforge_opens%
# using plugins like LeaderHeads or HolographicLeaderboards
