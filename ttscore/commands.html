Commands and permissions

TTSCore registers one command. It exists before any plugin loads.

Command Permission What it does
/ttscore version ttscore.command.version Shows the build this server is running. Also what /ttscore does with no argument
/ttscore reload ttscore.command.reload Reads ttscore.yml again and applies it to every loaded world
/ttscore info [world] ttscore.command.info Prints the settings in force in a world, each marked as its own or inherited

ttscore.command grants all three. Every node defaults to operators only.

/ttscore info completes world names with TAB.
