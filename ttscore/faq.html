FAQ

Will my plugins work?

TTSCore is Paper 1.21.11 with changes on top, and it leaves the plugin API as Paper has it. A plugin that runs on Paper 1.21.11 runs here. The full TTS-Studio suite runs on it.

Does it change anything when i first install it?

No. Every setting starts at its vanilla value. Until you edit ttscore.yml, the server plays like Paper.

Can i have cannons in one world and not in another?

Yes. Each world has its own block and inherits from default. See per-world settings.

Do i have to restart to try a value?

No. Edit the file and run /ttscore reload.

Something behaves oddly. is it TTSCore or the game?

Set raid.enabled: false in that world and reload. Every setting on this site goes back to vanilla at once. If the behaviour is still there, it is not ours.

I typed a value that makes no sense. what happens?

It is not applied. The console names the key and the server keeps the default for it.

Do i need DominionForge to use it?

No. DominionForge adds an in-game menu for these settings, and the file works without it.

Does DominionForge need TTSCore?

No. It is complete on plain Paper.

Which Minecraft versions?

1.21.11 today. TTSCore follows Paper's 1.21 line.

How do i get it?

On our store, for $50. The jar and the licence key are yours right after checkout.

What happens if the licence server is down?

Your server keeps running with its settings. Only a missing key or a key the store rejects locks them, and even then the server starts and runs as plain Paper.

I changed the key. do i have to restart?

No. Save the file and run /ttscore reload.
