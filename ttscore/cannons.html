Cannons

A cannon on plain 1.21 does not behave like a cannon on 1.8. Dispensed TNT leaves with a random sideways nudge, a thousand primed TNT are a thousand entities, and a shot can set off its own ammunition. The settings on this page put those behaviours back, one at a time.

All of them live under raid. in a world block. The full list with ranges is in the settings reference.

TNT

raid.tnt.dispense-straight
Dispensed TNT comes out straight. Without this a cannon is not repeatable, so it is the first one to turn on.
raid.tnt.merge and raid.tnt.merge-radius-y
TNT that shares position, velocity and fuse becomes one entity that counts as many. The shot is the same; the server does a fraction of the work. merge-radius-y is the vertical tolerance, and 1.05 is what merges a freshly dispensed column.
raid.tnt.column-dispensing
TNT dropped by several dispensers on the same tick into the same column is born already merged. This is the loading stage of a cannon.
raid.tnt.disable-chain-explosions
A TNT block caught in an explosion is not primed by it. Stops a cannon from detonating its own stock.
raid.tnt.fuse-ticks
Fuse length in ticks. 80 is vanilla.

Sand and other falling blocks

raid.falling-block.merge
The same merging, for falling blocks. Sand has to share position on all three axes to merge.
raid.falling-block.merge-places-all
When a merged stack lands, false places one block, as vanilla and 1.8 do. true places all of them.
raid.falling-block.disable-item-spawning
Falling blocks with nowhere to land drop no item. In a long shot those items cost more than the sand did.
raid.falling-block.tick-lifespan
How long a falling block lives. 600 is vanilla.
raid.falling-block.anti-lag-machine-threshold
How many falling blocks one chunk tolerates before all of them are removed. -1 turns the limit off. 2000 leaves room for a real cannon and stops a machine built to hurt the server.

Anvils

raid.anvil.explosion-resistance
-1 keeps Minecraft's value, 1200, which no cannon breaks. Around 1.0 an anvil breaks like a 1.8 one.
raid.anvil.pushed-by-piston
Lets a piston push an anvil. Vanilla never allows it; 1.8 factions servers did.

Exact parity

raid.legacy-precision applies TNT gravity and drag at the short precision 1.8 used. Leave it off unless you are matching a cannon built on 1.8 block for block.

A starting point for a cannon world

world-settings:
  factions:
    raid:
      legacy-precision: true
      tnt:
        merge: true
        column-dispensing: true
        dispense-straight: true
        disable-chain-explosions: true
      falling-block:
        merge: true
        disable-item-spawning: true
        anti-lag-machine-threshold: 2000
      anvil:
        explosion-resistance: 1.0
        pushed-by-piston: true

This is the profile we test against. Change one line, /ttscore reload, fire again.
