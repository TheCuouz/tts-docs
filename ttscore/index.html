TTSCore

The server under the plugins: 1.8 raiding on Paper 1.21

TTSCore is the server jar under the TTS-Studio plugins: a fork of Paper 1.21.11 that reaches the parts of the game a plugin cannot. Cannons that fire the same way twice, swings that land the way they did on 1.8, spawner rooms that stack, and chests that stay shut when somebody looks at them through a wall.

It runs like any Paper jar. Your plugins, your worlds and your start script stay as they are.

What it reaches

Area What you can set
Cannons TNT merging, dispensed TNT that flies straight, column dispensing, chain-explosion control, sand merging and how a merged stack lands
Anvils Blast resistance, and whether a piston may push one
Hit registration The server rescues a swing the client did not register, with a reach and a hitbox tolerance you choose
PvP timing Invulnerability between hits counted in real time instead of ticks, so a TPS dip does not slow a fight down
Spawners Light, spawn rules, entity obstruction, fixed spawn positions and birth velocity
Anti-freecam Chests, dispensers, signs and spawn eggs refuse to work through a block
Lag machines A ceiling on falling blocks per chunk, and no item drops from sand with nowhere to land

Three rules it keeps

  1. Nothing is on until you turn it on. A fresh TTSCore behaves exactly like the Paper it is built from. Every setting starts at its vanilla value.
  2. Everything is per world. Worlds inherit a default block and write only what they change, so the cannon world and the spawn world can disagree.
  3. Nothing needs a restart. /ttscore reload applies the file to every loaded world while players are online.

Works with DominionForge, required by nothing

DominionForge is complete on plain Paper. On TTSCore it detects the server and adds a page to /df adminconfig where every setting on this site can be changed with a click. New settings show up in that menu by themselves, because the server describes them to the plugin.

No TTS-Studio plugin refuses to start without TTSCore, and TTSCore does not need any of them.

Getting it

TTSCore is in closed testing on a live factions network. Access is handled by ticket in our Discord: open one, say what kind of server you run, and we take it from there.
