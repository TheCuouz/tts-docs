Plugins / AtlasForge

Getting it out

Schematics

/atlas export <name> [--format sponge|sponge2|mcedit|litematic]

Writes the WorldEdit selection to plugins/AtlasForge/schematics/. Block states and block entities (chests, signs, beds) go with it.

Format File Opens in
sponge (default) .schem, Sponge v3 WorldEdit, FAWE, Axiom
sponge2 .schem, Sponge v2 older WorldEdit and tools that have not moved to v3
mcedit .schematic legacy tools
litematic .litematic Litematica, straight into its schematics folder

From the console there is no selection, so give the two corners:

/atlas export town-east --from 700,60,700 --to 940,120,940 --world world

A top-down picture

/atlas render <x1> <z1> <x2> <z2> [world]

Saves a PNG of the area seen from above to plugins/AtlasForge/renders/.
