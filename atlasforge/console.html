Plugins / AtlasForge

Running it without a player

map, town, reroll, piece, culture, texture, export and render run from the console, over RCON, or from another plugin dispatching the command. They need to be told where, since nobody is standing anywhere:

atlas map 700 700 940 940 1492 hills --height 14 --base 68 --snow none --world world
atlas town 30 medieval 1492 --x 820 --z 820 --world world
atlas reroll --x 812 --z 835 --world world
atlas export town --from 700,60,700 --to 940,120,940 --world world

Long jobs answer at once and finish in the background. Over RCON the connection is usually closed before they do, so the result is written to the server log:

[AtlasForge] Map finished: 22303104 blocks in 7.202 s
[AtlasForge] Cellars: 9, 9 with a hatch
[AtlasForge] Town finished: 25 houses, 99178 blocks in 0.89 s
[AtlasForge] Reroll: plot 8 turn 1 · shed-back, 10×9, 2 volumes, 2 floors -> shed-side, 10×9, 2 volumes, 1 floor
[AtlasForge] Town refused at 100,100: no square fits · water 62% · built on 0% · steep 21%

A script that needs to know whether a town was built should read the log for Town finished or Town refused.
